# The BiomE Lab mark

Two sister lineages leave the same node, so they are exactly the same age.
One produced a single descendant. The other produced eight. That inequality is
the lab's research question, drawn.

The eight tips are also, not by accident, eight legs.

## Files

| File | Use |
|---|---|
| `mark.svg` | Full colour. Default for slides, posters, letterheads. |
| `mark-mono.svg` | Single colour, follows the surrounding text colour. Stamps, embroidery, faxes, engraving. |
| `mark-reversed.svg` | For dark backgrounds. |
| `../favicon.svg` | Dark tile version, used as the browser icon. |
| `../og-card.png` | 1200x630 card shown when the site is shared on social media. |

The header on the site draws the mark inline so it inherits the page colour;
that copy lives in `_tools/build.py`.

## Using it

- Keep clear space around the mark equal to the radius of one tip dot.
- Do not recolour the lone tip to match the eight. The colour difference is the
  whole argument.
- Minimum size is about 24 px; below that the tips merge.
- The palette is ink `#16211d`, teal `#14615c`, ochre `#9d6414`, stone `#e4e3da`.
