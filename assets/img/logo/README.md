# The BiomE Lab mark

Two sister lineages leave the same node, so they are exactly the same age.
One produced a single descendant. The other produced eight. That inequality is
the lab's research question, drawn.

The eight tips are also, not by accident, eight legs.

- Minimum size is about 24 px; below that the tips merge.
- The palette is ink `#16211d`, teal `#14615c`, ochre `#9d6414`, stone `#e4e3da`.
